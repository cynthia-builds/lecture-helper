## L01：课件数字与约束

来源：Systems Thinking_Lecture 3.pdf，PDF 第 6 页，印刷页码 44。测试输入为该页 1600 像素 PNG（460.3 KB）。

预先核对的检查点：9 名高级工程师；27 名技术员；3 名行政人员；15 台机器；$4M 预算；产量提高 30%；6 个月期限；提出两种方式。原文没有注明 $ 对应的币种。

Reading Check：成功返回。上述 8 个检查点均出现在结果中；这只是单页 8 个检查点的核对，不是整体准确率。

Bad Case：中文总结把 $4M 写成“400万美元”，未保留币种不确定性。英文事实只写 dollars。状态却仍是 ready，且声明没有明显不确定性。

人工纠正：通过现有 Edit / Correct Info 将预算事实改为“$4 M (4 million; currency unspecified in the source). Do not translate this as USD or SGD. 中文：400万，原课件未注明币种。”，点击 Save Corrections & Start Analysis。

Explain：成功返回具体中英文解释、案例分析、词汇、类比与课堂句式。页面的已验证事实保留了人工纠正；中文解释明确写出“原课件标注为$4 M，未注明具体币种”。本次人工纠正被后续生成采纳。

Explain Bad Cases：

- 将一般预算说成 capital expenditure budget，原文无此限定。
- 课堂句式提出购买或租赁 5 台机器，原文没有数量、单价或产能关系；虽置于建议句式中，仍需明确说明是假设方案，不能保证增产 30%。
- 把 machine downtime/breakdowns 解释成存量的流出，容易混淆机器数量与可用产能；短暂停机不必然减少机器数量。
- UI 固定文字“100% Grounded in AI Reading Check”过度承诺，不能作为质量指标。

Ask Doubt：成功。问题要求区分 USD、机器价格、买 5 台机器保证增产等是否来自原文，并要求简短中文。返回正确说明原文未指定币种、机器价格或增产保证；不过仍先返回较长英文，再附中文，未完全遵循语言与简短要求。

## L02：反馈回路图

来源：同一 PDF 第 12 页，印刷页码 53。测试输入为该页原样渲染 PNG（165.3 KB）。

核对依据：标题 Balancing Feedback Loop；别称 negative feedback；抵消变化、保持一定范围、稳定与自我纠正；右上图含 desired state、gap、action、current state 和正负号；左下 predator/prey B 回路；右下 imported cases/local transmissions/COVID cases/safe distancing measures B 回路。没有人物或机构正文。

Reading Check：成功。识别标题、印刷页码 53、负反馈定义、稳定作用，以及目标差距、捕食者/猎物、疫情三个示意图。COVID 图中正确识别输入流与安全距离措施对本地传播的反馈关系。没有逐条列出右上图正负号和全部有向边，因此不能宣称完整图结构识别通过。

Bad Case：模型输出 Nanyang Technological University (NTU Singapore)，该输入单页并无此标识。虽然完整课件归属 NTU，但单页提取不应把外部推断当作直接读到的内容。标为无重大遗漏也过于笼统。

UI Bad Case（无需 API 的复现）：完成 L01 分析后返回上传区、移除旧文件、上传 L02 并完成阅读检查；尚未确认 L02 或生成解释时，“Full Analysis”仍可点击。点击后显示 L01 的旧分析（Inflow, Outflow, Stock - Case Activity），而当前 Reading Check 是 L02 的 Balancing Feedback Loop。更换材料应清除或明确隔离旧分析，避免跨材料混淆。
