# Lecture Helper

面向国际学生的英语课件学习辅助 Web Demo。先核对模型读到了什么，再生成通俗中文、简化英文与课堂支持内容。

**状态：2026-10-14 功能冻结。现有 AI Studio 应用已实测运行；本仓库是该版本的完整源码导出与交付文档。不是已完成规模化验证的生产产品。**

## 用户问题与产品范围

目标用户是在英语授课环境学习的国际学生：课件里的专业术语、密集英文、数字约束和图示可能难以迅速理解；直接生成解释又可能把模型误读或推测当成课程事实。这是本项目要解决的用户问题假设，尚未通过用户访谈、真实用户量或学习效果研究验证。

产品选择把 **AI Reading Check + Human-in-the-loop** 放在解释前：先展示提取到的事实、理解总结、不确定性和可能遗漏，再由用户确认或修改。它提供检查机会，不保证用户确认后的内容全部正确。

## 核心流程

1. 粘贴课件文字，或上传材料。
2. `/api/check-reading` 调用 Gemini，返回事实、数字、中英文理解、不确定性与遗漏提示。
3. 用户检查内容，必要时通过 Edit / Correct Info 修改。
4. 确认后 `/api/explain-lecture` 基于原材料和已确认事实生成中文解释、简化英文、词汇、类比与课堂句式。
5. `/api/ask-doubt` 支持后续追问。

前端为 React + TypeScript + Vite；后端为 Express + TypeScript；通过 `@google/genai` 调用 `gemini-3.7-flash`。模型名称以当前冻结源码为准，未来可用性不作保证。没有 Agent、RAG 或向量数据库。

2026-10-14，通过现有 Web UI 实际调用：

## Bad Cases 与修复

| 问题 | 实际表现 | 冻结版本处理与验证范围 |
|---|---|---|
| 无依据补全币种 | `$4M` 被中文解释成美元 | 三个接口增加来源边界；同页回归主动标注币种未注明并提示核对 |
| 无依据补充原因、方案细节 | 补出市场需求增长、战略调整或新增 5 台机器 | 解释字段收紧；无来源原因改为未注明，建议和类比明确标假设；首轮回归仍失败，二次修正后通过固定检查点 |
| 材料切换残留分析 | 换页后还能打开上一页解释 | 文字/文件改变时清空相关状态；材料版本号忽略旧请求返回；文字修改与附件移除/上传实测通过，竞态保护仅代码检查 |
| 虚构机构 | 无机构的输入被补机构名称 | 来源约束已覆盖；该具体输入未再次调用回归，不声称已验证修复 |
| API 失败伪成功 | 接口异常后规则内容仍呈现为可分析 | **仍保留于冻结版本**，见下方边界 |

## 重要边界（展示时必须说明）

- 目前仍有内置预设、关键词命中预设及 API 失败的规则兜底。内置示例或“有结果”不能证明实时 Gemini 调用成功。真实演示使用非预设材料，出现 Heuristic 标记时不能声称真实生成成功。追问失败也可能返回通用文本。
- 部分页面仍显示 “100% Grounded” 等原有文案；这不是经过测量的质量结论，也不代表零幻觉。
- 模型约束降低无依据补全风险，但不能保证所有输入可靠；人工确认也可能漏错。
- 测试范围有限；完整 PDF、音频、长文档、模糊图片、不同模型、多用户环境和公开部署未验收。
- 历史分析保存在当前浏览器 localStorage。上传内容会发送给后端与 Gemini；不要公开提交私人课件或敏感内容。
- 现有服务未配置用户鉴权、服务端调用配额或硬性费用上限；不要把开发预览当成可无限开放的公共服务。公开源码与公开付费 API 服务是两回事。
- 当前冻结没有修复上述范围外问题，README 不把它们描述为已解决。

## 本地运行

前提：已安装与依赖兼容的 Node.js 和 npm，具备可用 Gemini API 项目与额度。下列命令来自项目现有配置，本次交付未重新做本地安装验收。

```sh
npm install
cp .env.example .env
# 在本机编辑 .env，填写自己的 GEMINI_API_KEY；不要提交该文件。
npm run dev
```

打开 `http://localhost:3000`。源码使用 `dotenv.config()` 默认读取 `.env`，不是 `.env.local`。

现有检查与生产命令：

```sh
npm run lint       # tsc --noEmit
npm run build
NODE_ENV=production npm start
```

`npm run preview` 只有 Vite 预览，不能替代完整 Express 后端。`/api/health` 的 geminiConfigured 仅说明检测到密钥，不验证余额或生成能力。

导出文件中 bun.lock 为空，不能提供可复现的锁定依赖版本；本次保留原导出，不伪称已锁定依赖。依赖清单中的重复 Vite 项也保留，未借交付阶段重构。
